# Chalana Gimhana

**Software developer in Sri Lanka building backend systems, automation tools, dashboards, and community products.**

I am a software development student and builder behind [NetchLK](https://netch.lk/) and co-founder of [AMcone](https://amcone.net/). I like turning real operational problems into software: dashboards for server work, bots that reduce manual admin tasks, and backend services that make data easier to use.

My work sits close to real operations. I build tools for hosting, communities, education, monitoring, and small business workflows, then keep improving them through actual use. I am interested in software engineering roles where I can contribute to useful products, learn from strong teams, and grow into backend, full-stack, or cloud-focused engineering work.

## Selected Work

These projects are the best quick view of how I think: practical tools, real workflows, and enough backend depth to be interesting.

- [DealBro](https://github.com/ChalanaGimhanaX/DealBro) - hosting deals search platform with FastAPI, MongoDB, Next.js, source adapters, duplicate detection, and filtering.
- [eightexmspos](https://github.com/ChalanaGimhanaX/eightexmspos) - POS system workspace with a WPF desktop client, FastAPI backend, device sync, update flow, and multilingual UI resources.
- [SLIITarchive](https://github.com/ChalanaGimhanaX/SLIITarchive) - university archive platform with document management, moderation, analytics, taxonomy, and a TypeScript web frontend.
- [Cloud-Manager](https://github.com/ChalanaGimhanaX/Cloud-Manager) - Discord bot and Flask OAuth dashboard prototype for managing server/client configuration workflows.
- [ExamBuddy](https://github.com/ChalanaGimhanaX/ExamBuddy) - quiz-practice app with React, TypeScript, question imports, progress tracking, Express APIs, and PostgreSQL.
- [Car Service and Maintenance Tracker](https://github.com/ChalanaGimhanaX/Car-Service-and-Maintenance-Tracker) - Spring Boot workshop system with roles, vehicles, service records, reminders, invoices, and audit logs.
